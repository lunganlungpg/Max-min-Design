1. Comparison Graphs

Let experimental groups be vertices K = {1, ..., K} and pairwise comparisons be edges P. For any connected graph, the contrast matrix has rank K - 1.

2. Wald Test Statistic & Invariance

T = R θ̂ᵀ (R Σ̂ Rᵀ)⁻¹ R θ̂

Theorem 2.1: The statistic T_ALL using all graph contrasts is identical to T based on any K - 1 linearly independent contrast rows.

3. Non-Centrality Parameter (Equation 9)

w_j = n_j / [θ_j (1 - θ_j)]
ϕ(n; θ) = Σ_{j=1}^{K-1} w_j (θ_j - θ_K)² - [Σ_{j=1}^{K-1} w_j (θ_j - θ_K)]² / Σ_{j=1}^K w_j

4. Optimal Max-Min Allocations

• Theorem 3.1 (Known Maximally Separated Pair):

Assign 50% to group i and 50% to group j: ξ_MM = (e_i + e_j)/2

• Theorem 3.2 (Complete Graph):

Balanced allocation: ξ_MM = (1/K, ..., 1/K)ᵀ

• Theorem 3.3 (Bipartite Graphs):

Degree-based rule: ξ_MM = 1/(2|P|) (d_1, ..., d_K)ᵀ

- Control vs Multiple: Control receives 1/2 of sample, treatments divide 1/2 equally.
- Path Graph (Dose-response): Endpoints receive 1/(2K-2), interior vertices receive 1/(K-1).
- Complete Bipartite: Half total sample to partition 1, half to partition 2.

5. Normal vs Bernoulli Response

Although optimal allocations coincide with normal responses, Least Favourable Configurations differ because the Bernoulli variance θ(1 - θ) is intrinsically tied to the success probability mean.

💡 Ph.D. Research Innovations by Lunganlung P G
Novel Contributions

As part of doctoral research at ICAR-IASRI, the following computational, methodological, and applied innovations were engineered by Lunganlung P G to translate Singh & Davidov's (2026) theoretical max-min framework into real-world agricultural and experimental practice:

1. Agricultural Seed-Emergence Experimental Translation

Formulated the 5-treatment agronomic trial (untreated control, hydro-priming, bio-priming, fungicide dressing, and integrated seed treatment, $N=480$ seeds) with day-10 emergence binary endpoints. Proved that Graph (b) degree concentration on Untreated Control and Bio-priming delivers a 30.88% seed savings (reducing required seeds from 693 to 479 for 90% power).

2. Discrete Integer Hamilton-Hare Exact Allocation Engine

Bridged the gap between continuous asymptotic theory $\xi_i \in (0,1)$ and real-world integer constraints $\sum n_i = N$. Implemented the Hamilton-Hare largest-remainder rounding algorithm with degree-priority tie-breaking, ensuring exact integer sample sizes without power degradation.

3. Dynamic Arbitrary Comparison Graph Engine with Bipartiteness Detection

Developed an interactive $K \times K$ adjacency matrix editor with real-time Breadth-First Search (BFS) 2-coloring for automated bipartiteness verification and cut-vertex connectivity checking, enabling agronomists to design non-standard comparison networks beyond standard trees.

4. 2D Multi-Parametric Power Sensitivity & Robustness Explorer

Created a 2D sensitivity matrix surface evaluating design stability against uncertain prior response rates ($\theta_c \in [0.20, 0.60]$) and effect sizes ($\delta \in [0.15, 0.45]$) using Poisson-mixture non-central $\chi^2$ CDF inversion.

5. Operational Field & Lab Randomized Plot Allocation Engine

Engineered an experimental execution tool converting optimal group sizes into randomized field plot and nursery tray assignments via the Fisher-Yates algorithm, complete with downloadable CSV field plans and printable PDF protocols.

6. Cross-Platform Deployable Ecosystem (Android APK + PWA + R/Python Packages)

Packaged the entire suite into a standalone signed Android APK (API 21-35, Android PrintManager, MediaStore, ShareSheet), a Progressive Web App (PWA) with offline caching, and reproducible R 4.5.1 and Python 3.12 packages for open science.
